# Personal Finance Visualizer

A simple web app to track your income and expenses, built with **Next.js 14 App Router**, **MongoDB**, **Tailwind CSS**, and **Shadcn UI**.

---

## ✨ Features

- Add income and expense transactions.
- View all transactions in a list.
- Visualize your monthly finances with a bar chart.
- Data is stored in MongoDB Atlas.

---

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- React
- MongoDB (via Mongoose)
- Tailwind CSS
- Shadcn UI Components

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/personal-finance-visualizer.git
cd personal-finance-visualizer
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file in the root folder:

```
MONGODB_URI=your-mongodb-connection-uri
```

> Example: `mongodb+srv://username:password@cluster.mongodb.net/your-db-name`

---

### 4. Run the development server

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the app.
